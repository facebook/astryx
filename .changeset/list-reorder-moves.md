[feat] A reorderable `List`'s handle, activated without a drag (a tap, a click, a screen reader's double tap), opens its row's moves: Move up, Move down, Move to top and Move to bottom, each offered only when it moves the row, so a row can be reordered with a single pointer and no drag. `ListItem`'s new `reorderLabel` names the handle of a row whose label is not plain text.
