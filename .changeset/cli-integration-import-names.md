[feat] `astryx doctor integration validate` now also lists, from source and without a build, an import that names something its module does not export, as notes on its result (`data.notes`, each with its fix in the message). The notes are listed only: neither `doctor integration validate` nor `astryx integration check --strict` counts them or fails on them in 0.7.3, and they become failing warnings in the next minor release, so fix them now. It notes a component's import (the doc's `import`, or the one the CLI derives when the doc has none) that leads to a module that does not export the component, naming the subpath that does or the `exports` entry to add; a component example or a template that imports a name the package does not export; and a template source with no default export (`astryx template` still copies it, but its public import and anything that renders it get nothing), suggesting an exported function or class, or another PascalCase value. A name is judged only when a file the `exports` entry names is there to read in full: `export *` is followed, cycles included; a built module's declaration file (`x.d.ts` beside `x.js`, and the `.d.ts` files a declaration file's `export *` names) is read for the types it exports; and `export import Alias = Inner.Value` counts as an export. TypeScript source resolves a `./x.js` specifier to `./x.ts`, and a declaration file that is a module exports every top-level declaration unless it has an export list, `export *`, `export =` or a default export of an expression, as TypeScript does. Whatever the reader does not fully model is listed under `unchecked` in the `publicImports` report instead of as a note: a file the `exports` entry names that does not exist yet, a module whose list cannot be read in full (CommonJS, `export *` from another package), a declaration file with no import or export (a global script), or a name missing from a JavaScript module with no declaration file, which may be a type. An example that imports only inline `type` names from a `types`-only subpath is told to write `import type`.
