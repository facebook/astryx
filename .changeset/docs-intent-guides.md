[docs] `astryx docs` now lists twelve guides, each named for what you want to do, then Reference: `get-started`, `work-with-agents`, `build-a-page`, `find-a-component`, `theme-your-app`, `style-components`, `foundations` (with `tokens` and `typography` beside it, as before), `check-your-code`, `upgrade-and-migrate`, `translate-your-app`, `make-an-integration`, `fix-a-problem`, and `reference`, each with a one-line promise. Every Core doc sits under exactly one of them, and the second "Topics" list is gone. New short guides: `find-a-component/by-job` (the component for each job), `upgrade-and-migrate/upgrade`, `check-your-code/doctor`, and `fix-a-problem/report-a-gap`. The theme guides are one guide. Foundations is unchanged: the same topics, names, and routes. Docs moved: `getting-started` is `get-started/add-to-a-project`, `working-with-ai` is `work-with-agents/agent-setup`, `theme` is `theme-your-app`, `use-a-theme` and `author-a-theme` are under `theme-your-app`, `styling-overview` is `style-components/css-setup`, `principles` is `get-started/principles`, `is-my-code-good` is `check-your-code/agent-review`, `use-integrations` is `find-a-component/use-integrations`, `layout/…` is `build-a-page/…`, `styling/…` and `styling-libraries/…` are `style-components/…`, `internationalization/…` is `translate-your-app/…`, `migration/…` is `upgrade-and-migrate/move-an-app/…`, `global/…` is `get-started/on-your-computer/…`, `authoring/…` is `make-an-integration/…`, and `cli/commands`, `cli/api`, `cli/host-entry`, and `browser-support` are under `reference`. An old route's error names its new route. An integration topic that extends or replaces a former Core topic by its old name, or links to it, still reaches the guide that holds its text.

Compatibility: `docs.detail.data.links.previous` stays in the JSON contract. It was always absent on the first topic of a level, and an integration's flat topic now sits in More topics without Core's topics before it, so an integration's first topic reads without it; a consumer of v0.7.2 already handles it absent.
