Install in your app (paths are relative to a file in src/ — adjust if yours lives elsewhere):

  import { astryxTheme } from './themes/astryx';

    <App />
  </Theme>

Or with a <link> tag:

  import { astryxTheme } from './themes/astryx';

  <link rel="stylesheet" href="./themes/astryx.css" />
  <Theme theme={astryxTheme}>
    <App />
  </Theme>
