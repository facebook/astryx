A button initiates an instantaneous action.

Buttons are clickable elements used to trigger actions. They communicate calls to action to the user and allow users to interact with pages in a variety of ways. Button labels express what action will occur when the user interacts with it. Buttons can contain a combination of a clear label and an icon, while standalone icon buttons are reserved for recurring, universally understood actions.

When to use

  • Triggering form submissions or confirming a dialog
  • Navigating to a new page or view within the application
  • Starting a new process or workflow (e.g., "Create new")
  • Toggling a UI element or performing an inline action
  • Performing destructive actions such as deleting items; use the danger variant for these
