Astryx CLI
Commands, programmatic APIs, and output contracts. Building an integration is under `pnpm exec astryx docs authoring`.

package: @astryxdesign/cli

Use the CLI in any folder: install it once for your computer, and every project still gets the release that matches its
Core. See `pnpm exec astryx docs global`.

Guides

component-lookups  Look up one or several exact component identities, choose a focused projection, and handle complete
                   batch receipts.
host-entry         Run the Astryx CLI from your own command-line tool: the inputs `runHostedCli` takes, what it returns,
                   and when the process ends instead.

Reference

commands  Every command and subcommand: usage, options, examples, exit codes, and what it does outside a project.
api       The programmatic API: functions, the JSON output envelope, error codes, and response types.

Open one: pnpm exec astryx docs cli/<name>
Up: pnpm exec astryx docs
